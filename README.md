# V8 Engine — Interactive 3D Mechanics Lab

A browser-based educational V8 engine experience inspired by the SAEID ENGINE / Engine Lab visual language.

## Features
- Procedurally built 90° V8 engine with two banks of four cylinders
- Animated crankshaft, eight pistons/connecting rods, camshaft, valves and ignition events
- Interactive component picking and system highlighting
- Exploded, X-ray, cutaway, isolate and label modes
- Intake, fuel, ignition, exhaust, cooling, lubrication, timing, accessory and flywheel assemblies
- Separate interactive four-stroke combustion cutaway showing intake, compression, power and exhaust
- Responsive desktop/mobile interface
- No external 3D asset dependency: the engine is generated in Three.js at runtime
